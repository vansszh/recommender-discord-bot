# Discord Server Recommender

Small mini project by Vansh Sharma and Aditya Aman.

## Run

```powershell
pip install -r requirements.txt
python main.py
```

Add the bot token and `groq_api` key to `.env` first.

The bot uses `servers.json` and has commands for search, categories, popular servers, random servers, and reload.

The report source is `recommender_systems_report.tex`.
